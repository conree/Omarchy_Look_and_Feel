# Look & Feel 0.3.1

## What's changed

- Turn automatic repair on or off in Appearance. When off, sunrise/sunset
  theme switching and background status checks also pause; manual Apply and
  Undo remain available, and the shell font binding stays active.
- Get clearer guidance on which applications to close or reopen and when to
  sign out and back in for Qt integration.
- The panel requests Montserrat for interface text; if it is not installed,
  the system supplies a fallback. Font previews use their selected fonts and
  unsupported glyphs use fallbacks. Explanatory text wraps in the left column.
- See a refreshed Marketplace description and preview.

Qt integration and its existing package requirements remain in place. See the
[installation instructions](https://github.com/conree/Omarchy_Look_and_Feel#install) for setup.
