Shared control layers and conflicts

LayerLocal evidenceEffect on the design
GTK 3 and GTK 4 ~/.config/gtk-3.0/settings.ini sets Visby CF 14; ~/.config/gtk-4.0/settings.ini sets Visby CF Medium 14. The GSettings probe returned font-name=Visby CF Medium 14, document-font-name=Avenir Next 12, monospace-font-name=Comic Code Ligatures 11, and text-scaling-factor=1.0, but warned that its dconf runtime path is unavailable in this inspection environment. GTK theme/icon preferences are separate. Fish exports GTK_THEME=Dracula-Van-Helsing. PCManFM is GTK 3. GTK settings files and GSettings/dconf are distinct inputs and can disagree; the selected GTK generation and runtime settings backend must be verified per app. A system-font adapter must account for both GTK generations and decide explicitly whether the separate document and monospace defaults follow the system selection. The Shell Font plugin does not update either GTK source. GTK CSS/theme rules and environment overrides also need checking.
GTK theme CSS The selected Dracula-Van-Helsing GTK 3 and GTK 4 theme stylesheets contain explicit widget font sizes and a Monospace family rule. ~/.config/gtk-3.0/gtk.css is an additional user override layer. Theme CSS can override family, weight, or size for selected widgets even when GTK's base font setting is correct. Re-scan the selected theme and user CSS after theme changes, and distinguish those scoped rules from a global font selection.
Fontconfig ~/.config/fontconfig/fonts.conf prepends Comic Code Ligatures for the generic monospace family. Rules in conf.d alias Visby to Visby CF, define preferred sans/serif/monospace fallback chains, and set font scale 1.5 and DPI 75. Fontconfig affects family matching and rendered metrics for applications that request generic families; it does not set GTK's widget font name. Omarchy's omarchy-font-set rewrites the monospace alias, and Font Manager owns some display-property rules. Preserve and reconcile these rules without replacing unrelated configuration.
Qt 5/6 qt5ct.conf and qt6ct.conf define Avenir Next 12 general, Comic Code Ligatures 12 fixed, and a custom Dracula palette. The active Hyprland config search did not find QT_QPA_PLATFORMTHEME=qt5ct/qt6ct; archived configs do contain it. These files show competing values, but their current reach in this session is not established. Confirm the live Qt platform-theme environment and test representative Qt apps before making qt5ct/qt6ct an authority adapter.
Omarchy theme/font/size commands omarchy-font-set rewrites Alacritty, Kitty, Ghostty, Foot, the fontconfig monospace alias, and restarts Quickshell before running font hooks. omarchy-display-text-size changes Quickshell base size, GNOME/GTK text-scaling-factor, and sizes in four terminal configs. The user's fontsize fish function separately rewrites sizes in five terminal configs and restarts terminals. Theme changes and hooks may also rewrite app configuration. These are competing writers, not passive settings. Look_and_Feel must reassert its owned values after each relevant command/hook and preserve unrelated keys. Omarchy's commands do not cover every app-specific adapter; the fish function additionally covers WezTerm.
Omarchy Shell Font plugin skuthus.shell-font is listed in ~/.config/omarchy/shell.json. Its active selection is Avenir Next Regular. The plugin loads a generated face and sets Quickshell’s Style.fontFamily; its code does not write GTK settings. The GTK 3 font remains Visby CF 14. This plugin only controls Omarchy’s Quickshell bar and shell UI. It neither promises nor applies a desktop-wide system font. Look_and_Feel must implement its own GTK 3/4 adapters; its current prototype is read-only and does not yet apply any settings.
Display scaling and rendering The GSettings probe returned GNOME text scaling 1.0 and separate antialiasing, hinting, and subpixel-order values; its dconf runtime path was unavailable here, so verify them in-session. Hyprland monitor scale is 1.5 and GDK_SCALE is 1.33. Fontconfig's display-properties rule sets font scale 1.5 and DPI 75. These controls change apparent size or rasterization without changing the selected family/point size. Record and verify them when comparing visible size; do not silently change monitor layout, scale, or rendering preferences as part of a font-family selection.
Background and icons Omarchy theme setter can change the wallpaper as a side effect. GTK 3/4 icon theme currently comes from settings files. Dropdown inventory reads live theme wallpaper directories, ~/.config/omarchy/backgrounds/, the current wallpaper, the owner's personal wallpaper library, and XDG icon directories. Use the canonical background choice separately from theme application and suppress Omarchy’s automatic theme wallpaper replacement. GTK icon choice has a direct control point; Qt and app-owned icon coverage still needs proof.

Implementation gates

  1. Define the saved settings schema so system font, terminal font, Light theme, Dark theme, mode, background, and icon theme remain independent.
  2. Implement reversible, narrowly scoped adapters for GTK 3/4, fontconfig, each terminal, and the active shell/browser/app-specific font controls. Reassert after Omarchy font, size, and theme actions; preserve theme/background separation.
  3. Resolve the active Qt integration and ONLYOFFICE’s app-owned UI settings before claiming those targets.
  4. Treat Brave/HEY web content and office document content separately from app chrome. Decide and prove the required enforcement boundary before listing them as supported.
  5. Do not mark any target supported until family, visible size, theme/color, and relevant icon/background behavior survive relaunch and the known competing-setting actions.
