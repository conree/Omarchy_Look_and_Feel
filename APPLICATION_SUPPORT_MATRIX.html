Shared control layers and conflicts

LayerLocal evidenceEffect on the design
GTK 3 and GTK 4 ~/.config/gtk-3.0/settings.ini sets Visby CF 14, Dracula-Van-Helsing, Tela-circle Dracula icons and prefers light at the GTK setting. ~/.config/gtk-4.0/settings.ini sets Visby CF Medium 14, the same theme/icons, and Adwaita prefer-dark. Fish also exports GTK_THEME=Dracula-Van-Helsing for programs launched from that shell. One “system font” value must write both GTK generations consistently and coordinate the shell environment override. Per-app CSS or app-specific settings can still diverge and need inventory/verification.
Qt 5/6 qt5ct.conf and qt6ct.conf define Avenir Next 12 general, Comic Code Ligatures 12 fixed, and a custom Dracula palette. The active Hyprland config search did not find QT_QPA_PLATFORMTHEME=qt5ct/qt6ct; archived configs do contain it. These files show competing values, but their current reach in this session is not established. Confirm the live Qt platform-theme environment and test representative Qt apps before making qt5ct/qt6ct an authority adapter.
Omarchy theme/font/size commands omarchy-theme-set retints a list of apps, runs theme hooks, and normally sets a theme-associated background; OMARCHY_THEME_SKIP_BACKGROUND=1 skips that background replacement. omarchy-font-set rewrites Alacritty, Kitty, Ghostty and Foot, updates fontconfig, restarts shell, and runs the font hook. omarchy-display-text-size rewrites terminal sizes and the GTK text scale. Adapters must reassert owner preferences after these commands. Theme application must preserve the independently chosen wallpaper. The existing font and size commands do not cover WezTerm.
Omarchy Shell Font plugin skuthus.shell-font is listed in ~/.config/omarchy/shell.json, and its config currently enables Visby CF Medium. Its loaded service reads that config and applies it at shell startup. This is a direct competing authority for shell UI text. The Look and Feel adapter must coordinate with it or it will reassert its own family after shell restart.
Background and icons Omarchy theme setter can change the wallpaper as a side effect. GTK 3/4 icon theme currently comes from settings files. The independent catalog snapshot is at ~/.local/share/omarchy-look-and-feel/catalogs/. Use the canonical background choice separately from theme application and suppress Omarchy’s automatic theme wallpaper replacement. GTK icon choice has a direct control point; Qt and app-owned icon coverage still needs proof.

Implementation gates

  1. Define the saved settings schema so system font, terminal font, Light theme, Dark theme, mode, background, and icon theme remain independent.
  2. Implement reversible, narrowly scoped adapters for GTK 3/4 and each terminal. Reassert after Omarchy font, size, and theme actions; preserve theme/background separation.
  3. Resolve the active Qt integration and ONLYOFFICE’s app-owned UI settings before claiming those targets.
  4. Treat Brave/HEY web content and office document content separately from app chrome. Decide and prove the required enforcement boundary before listing them as supported.
  5. Do not mark any target supported until family, visible size, theme/color, and relevant icon/background behavior survive relaunch and the known competing-setting actions.
